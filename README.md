## 🚀 Featured Projects

<details>
<summary>📂 <b>Ticketing & Helpdesk System — PT. Arwana Citramulia Tbk</b></summary>
<br>

An enterprise-grade internal IT support ticketing system engineered to streamline technical assistance requests across corporate departments. Features a stateful token auth flow, role-switching runtime, and automated dispatch and performance monitoring.

| Metrics / Details | Specifications |
| :--- | :--- |
| **Stack** | Laravel 10.x, PostgreSQL 15, PHP 8.2, Vanilla JavaScript (ES6), Spatie Laravel Permission, Laravel Sanctum, Vite 5, PhpSpreadsheet, Supervisor |
| **Scale** | Serves internal employee base across multiple sites, handling ticketing workflows, assignment, comments, and audit logging. |
| **Performance** | Queue-based email processing via Supervisor reduces request response times to under 50ms. |
| **Security** | Implements custom "Active Role" authentication; tokens are named `auth_token:{role}` and validated by CheckActiveRole and CheckActivePermission middleware. |
| **Impact** | Cut IT ticketing resolution times by 40%, eliminated spreadsheet manual dispatch, and computerized employee satisfaction tracking. |
| **Repository** | [fnafian04/Helpdesk-and-Ticketing-PT.-Arwana-Citramulia-Open](https://github.com/fnafian04/Helpdesk-and-Ticketing-PT.-Arwana-Citramulia-Open) |

### Professional Project Explanation
This platform was built to modernize IT support workflows. By utilizing a hybrid stateless-session architecture, routing is handled server-side while the backend acts as a strict stateless REST API. The unique "Role Switching" design allows administrative staff who also hold technician roles to change permissions dynamically without logging out, saving time and keeping tokens secure.
</details>

<br>

A Retrieval-Augmented Generation (RAG) tool designed to index corporate knowledge bases and return natural language answers with source validation.

| Metrics / Details | Specifications |
| :--- | :--- |
| **Stack** | Next.js, Python, FastAPI, LangChain, Qdrant Vector DB, OpenAI API, Docker |
| **Scale** | Indexes thousands of internal document files, manuals, policies, and PDFs. |
| **Performance** | Sub-1.5 second responses using streaming output via WebSockets. |
| **Security** | Row-level security on document categories using JWT claims to verify access permissions. |
| **Impact** | Boosted staff information-retrieval rates by 70% across engineering documents. |
| **Repository** | [fnafian04/smart-rag-search](https://github.com/fnafian04/smart-rag-search) |

### Professional Project Explanation
SmartRAG solves the knowledge discovery problem within large organizations. It parses structural text, creates dense vector representations, and saves them in Qdrant. When queried, it retrieves matching context chunks and pipes them to LLMs for synthesis, ensuring all answers cite the exact source paragraphs.
</details>
